# idea-to-tickets

把模糊想法经 clarify→spec→slice→explain 四步变成 Agent 可稳定执行、可独立验收的工单；另含架构师/开发/产品/秘书职能分工与领域专家角色扩展方法。方法论与 IDE、任务系统解耦，可跨 Agent 平移。

## 使用

这是豆包（及兼容 Agent）的**本地技能（Skill）**。完整能力、触发场景与操作流程见入口文档 **[`SKILL.md`](SKILL.md)**，Agent 命中时首先读取它；下列子目录按需加载，不必一次全读。

## 目录

- `SKILL.md`：技能入口与路由
- `references/`：按需细读的参考文档
- `templates/`：产出模板
